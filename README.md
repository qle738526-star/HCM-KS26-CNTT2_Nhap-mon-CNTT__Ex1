# HCM-KS26-CNTT2_Nhap-mon-CNTT__Ex1
**PHẦN 1: PHÂN TÍCH VẤN ĐỀ**
1. Phép tính sai: Bước đổi 1000 ảnh từ MB sang GB: 4000 MB = 4 GB.
2. Nguyên nhân: Chia cho 1000 thay vì 1024. Tính đúng: 4000 / 1024 = 3.91 GB. Vì dữ liệu chiếm ít hơn 4 GB nên dung lượng trống thực tế hiển thị cao hơn 112 GB.

**PHẦN 2: HOÀN THIỆN BÀI LÀM**
1. Tổng dung lượng sử dụng:
Công cụ lập trình: 40 GB
1000 ảnh: 4 MB * 1000 / 1024 = 3.91 GB
50 phim: 2 GB * 50 = 100 GB
=> Tổng dung lượng dùng = 40 + 3.91 + 100 = 143.91 GB
2. Dung lượng còn trống:
=> Dung lượng trống = 256 - 143.91 = 112.09 GB
3. Lưu thêm 500 bài MP3:
Dung lượng 500 bài MP3 = 5 MB * 500 / 1024 = 2.44 GB

So sánh: Dung lượng trống 112.09 GB lớn hơn 2.44 GB
=> Kết luận: HOÀN TOÀN ĐỦ. Lưu xong máy còn trống 112.09 - 2.44 = 109.65 GB.
